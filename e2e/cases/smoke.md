# 스모크

화면이 에러 없이 열리는지만 본다. 기능은 화면별 케이스 파일에서 다룬다.
모든 케이스는 데스크톱과 모바일(Pixel 7) 두 크기로 돈다.

### TC-SMOKE-001 소개 화면이 열린다
- 우선순위: P1 / 태그: @smoke / 상태: 구현됨

### TC-SMOKE-002 로그인 화면에 Google 로그인 버튼이 있다
- 우선순위: P1 / 태그: @smoke / 상태: 구현됨

### TC-SMOKE-003 약관과 개인정보 처리방침이 열린다
- 우선순위: P2 / 태그: @smoke / 상태: 구현됨

### TC-SMOKE-004 로그인이 필요한 화면은 로그인 화면으로 보낸다
- 우선순위: P1 / 태그: @smoke / 상태: 구현됨
- 절차: 로그인 없이 `/home` 진입
- 기대: `/login` 으로 이동

### TC-SMOKE-005 없는 주소는 404 화면을 보여 준다
- 우선순위: P3 / 태그: @smoke / 상태: 구현됨

### TC-SMOKE-010 로그인한 사용자에게 각 화면이 열린다
- 우선순위: P1 / 태그: @smoke / 상태: 구현됨
- 전제: 데이터가 없는 새 사용자
- 기대: 홈·카테고리·루틴·기록·마이가 각자의 제목과 함께 열린다

### TC-SMOKE-011 헤더 메뉴로 모든 화면을 오간다
- 우선순위: P1 / 태그: @smoke / 상태: 구현됨
