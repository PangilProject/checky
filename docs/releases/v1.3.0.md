# v1.3.0

- 릴리즈일: 2026년 8월 9일
- 대상 커밋: `246dc17`
- 이전 버전: [v1.2.0](./v1.2.0.md)

## 🚀 Overview

v1.2.0이 평소에 쓰는 흐름을 점검한 릴리즈였다면, 이번은 **바닥을 다진 릴리즈**입니다.

두 가지 전수 감사를 진행했습니다. 하나는 **Firestore 비용 감사** — 화면 하나를 열 때마다,
항목 하나를 저장할 때마다 서버를 몇 번 읽고 쓰는지 전 경로를 추적해 13가지 낭비를 찾아
전부 없앴습니다. 다른 하나는 **날짜/시간 처리 감사** — 자정을 넘길 때, 달이 바뀔 때,
요일을 바꿀 때 화면이 실제와 어긋날 수 있는 지점을 찾아 수정했습니다.

겉으로는 조용한 릴리즈지만 숫자는 큽니다. 같은 사용을 기준으로
**루틴 저장 시 읽기 72% 감소, 일괄 작업 읽기 약 1,100회 → 24회, 세션당 카테고리 읽기
약 48회 → 6회, 연속 드래그 쓰기 100회 → 20회.** 무료 한도 안에서 더 많은 사용자를
감당할 수 있게 됐습니다.

## ✨ Features

- 마이페이지에 관리자 진입점 추가 (관리자 계정에만 보입니다)
- 관리자 사용자 상세에서 가입일·마지막 로그인·마지막 접속을 시:분까지 표시

## ⚡ Improvements

- 화면 전환·재방문 시 서버를 다시 읽지 않도록 앱 전체 캐시 정책을 정비했습니다
- 할 일·루틴을 바꿨을 때 달력 집계를 통째로 다시 세지 않고 **바뀐 몫만 다시 셉니다**
- 카테고리 조회를 하나의 캐시로 통일해 화면마다 따로 읽던 중복을 없앴습니다
- 루틴 화면이 분류 수만큼 반복하던 조회를 한 번의 조회로 줄였습니다
- 주간 리포트의 조회를 병렬로 바꿔 로딩을 단축했습니다
- 드래그로 순서를 바꿀 때 드롭마다 저장하지 않고 **마지막 상태만 저장**합니다
  (저장 실패 시 이제 토스트로 알리고 서버 순서로 복원합니다 — 이전에는 조용히 실패했습니다)
- 루틴을 지우면 지난 수행 기록도 함께 정리되어, 남은 기록이 이후 조회 비용으로 쌓이지 않습니다
- 회원 탈퇴 시 데이터 삭제를 배치 처리로 전환해 대량 데이터에서도 안정적으로 지워집니다
- 관리자 대시보드·사용자 목록이 캐시를 사용해 왕복할 때마다 전체를 다시 읽지 않습니다

## 🐛 Fixes

- 자정을 넘겨도 홈 화면이 어제를 오늘처럼 보여주던 문제
  이제 날짜가 바뀌면 자동으로 새 오늘을 따라갑니다 (과거 날짜를 보고 있었다면 그대로 둡니다)
- 날짜 선택기의 "오늘" 표시가 열어 둔 세션에서 어제에 머물던 문제
- 루틴의 반복 요일을 바꿨는데, 예전에 예약해 둔 미래 변경이 남아 있으면
  그 날짜부터 조용히 옛 요일로 되돌아가던 문제
- 오래전에 만든 루틴이 주간 리포트에는 안 보이는데 달력에는
  체크할 수 없는 미완료로 남던 문제 (리포트와 달력의 표시 규칙을 통일했습니다)
- 할 일을 추가한 직후 경과일 표시가 뜨지 않던 문제
- 할 일을 다른 날짜로 옮길 때 완료 기록이 중복으로 쌓일 수 있던 문제
- 완료 체크가 집계 문서에서 그날을 찾지 못하면 어긋난 채 남던 문제
  이제 그 자리에서 다시 세어 맞춥니다
- 관리자 화면을 오래 열어 두면 "3일 내 활성" 판정이 열어 둔 만큼 밀리던 문제
- 관리자 사용자 목록이 모바일에서 세로로 줄바꿈되어 깨져 보이던 문제
- 관리자 상세의 "최근 접속 N일 전"이 24시간 단위라 어제 접속이 "0일 전"으로 보이던 문제
  이제 달력일 기준으로 셉니다

## ⚠️ Notes

**오래전에 만든 루틴의 달력 숫자가 조정될 수 있습니다.**
반복 이력이 없던 시절의 루틴은 마지막 수정일 이전 날짜를 달력에서도 세지 않도록
규칙을 통일했습니다. 리포트에서 체크할 수 없던 미완료가 달력에서 사라지는 방향의
조정이며, 실제 기록이 있는 날은 그대로 남습니다.

**순서 저장이 약 0.8초 뒤에 이루어집니다.**
드래그 직후 바로 탭을 닫아도 대부분 저장되지만(닫힘 감지 시 즉시 저장),
화면에는 항상 즉시 반영되므로 체감 차이는 없습니다.
