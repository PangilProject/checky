# v1.5.0

- 릴리즈일: 2026년 9월 27일
- 대상 커밋: `a27adb7`
- 이전 버전: [v1.4.0](./v1.4.0.md)

## 🚀 Overview

v1.4.0이 화면을 다시 칠한 릴리즈였다면, 이번은 **쌓인 기록을 읽을 수 있게 한 릴리즈**입니다.

그동안 Checky는 체크를 모으기만 하고, 그 기록을 다시 볼 자리는 달력의 남은 개수 정도였습니다.
이번에 홈 맨 위에 주간·월간 달성 현황을 두고, 루틴 하나하나의 수행 기록을 볼 수 있게 하고,
한 주나 한 달을 돌아보는 기록 화면을 새로 만들었습니다. 할 일 목록에는 한 주를 한눈에 보며
몰린 날의 할 일을 다른 날로 끌어 옮기는 보기를 더했습니다.
어느 화면도 잘했다·못했다를 말하지 않습니다. 숫자와 목록만 보여 주고 판단은 쓰는 분께 맡깁니다.

처음 찾아온 분을 위한 소개 페이지도 새로 만들었습니다. 첫 화면이 스크롤을 따라 흐르는
짧은 소개 필름이 되었고, 로그인 화면은 `/login`으로 옮겼습니다.

## 🔒 Security

- **공지 저장 시 내용도 서버에서 검사합니다.** 지금까지 보안 규칙은 관리자인지만 확인하고
  제목·내용의 길이는 보지 않았습니다. 화면의 글자 수 제한은 앱을 거치지 않으면 통하지 않으므로,
  허용 필드와 제목·내용 길이 상한을 규칙에 추가했습니다
- 저장된 글을 HTML로 해석하는 코드를 쓰지 못하게 린트 규칙으로 막았습니다.
  사용자가 입력한 값은 화면에 글자로만 나오는 것이 이 앱의 방어선이라, 그 통로가 생기지 않게 고정했습니다

## ✨ Features

- **소개 페이지를 새로 만들었습니다.** 첫 화면(`/`)에서 스크롤을 내리면 빈 체크 하나에서 시작해
  할 일 목록, 주간 루틴 표, 달력, 달성 현황을 차례로 지나갑니다. 방문자가 직접 체크해 볼 수 있고,
  움직임 줄이기를 켠 분께는 같은 장면을 멈춘 채 보여 드립니다
  - 첫 화면에 스크롤 안내를 두었습니다
  - 로그인 화면에서 소개 페이지로 돌아갈 수 있습니다
- **홈 맨 위에 달성 현황을 추가했습니다.** 선택한 날짜가 속한 주나 달에 할 일과 루틴을
  오늘까지 몇 개 해냈는지, 지난 기간의 같은 시점과 비교해 보여 줍니다.
  주간은 요일별, 월간은 주차별 막대로 보여 주고 오늘 이후는 예정으로만 표시합니다
- **루틴 기록을 볼 수 있습니다.** 루틴 페이지에서 루틴 이름을 누르면 최근 1·3개월 수행 달력,
  요일별 횟수, 반복 요일을 바꾸기 전과 후의 횟수가 나옵니다
- **할 일 목록에 한 주 보기를 추가했습니다.** "하루 | 한 주"로 전환하면 일요일부터 토요일까지
  날마다 할 일과 루틴이 얼마나 있는지 나란히 보입니다. 할 일을 길게 눌러 다른 날로 옮길 수 있고,
  날짜를 누르면 그날 목록으로 돌아갑니다
- **기록 화면을 추가했습니다.** 헤더의 "기록"에서 한 주나 한 달 동안의 달성률, 해낸 할 일,
  루틴 수행, 남은 할 일, 분류별로 해낸 할 일, 루틴별 수행을 볼 수 있습니다.
  루틴을 누르면 그 루틴의 기록이 열립니다
- 마이 페이지에서 최근 6개월 달성률을 볼 수 있습니다
- 루틴 표 아래에 요일별 합계 줄을 추가했습니다
- 할 일 목록에 그날 끝낸 개수("3 / 5 완료")와 분류별 개수를 표시합니다
- 달력의 남은 개수 둘레에 완료 비율 링을 그립니다.
  10개 중 2개 남은 날과 3개 중 2개 남은 날이 이제 다르게 보입니다

## ⚡ Improvements

- **고치던 내용이 실수로 사라지지 않게 했습니다.** 할 일·카테고리·루틴·공지 창에서
  수정하던 내용을 두고 나가려 하면 한 번 더 묻습니다. 고친 데가 없으면 저장 버튼이 눌리지 않습니다
- 수정을 누르거나 새로 만들 때 첫 입력창에 바로 커서가 들어갑니다.
  커서는 글자 끝에 두어 기존 내용 뒤에 이어 쓸 수 있습니다
- 창마다 달랐던 버튼 이름을 "취소 / 저장"으로 통일했습니다
- 홈 화면에 설치한 앱은 소개 페이지를 거치지 않고 홈에서 바로 시작합니다
- 좁은 화면에서 섹션 머리의 버튼이 많아지면 제목을 밀어내지 않고 다음 줄로 내려갑니다

## 🐛 Fixes

- 창이 겹쳐 떠 있을 때 ESC를 누르면 모든 창이 한 번에 닫히던 문제.
  이제 맨 위 창만 닫힙니다
- 카테고리·루틴 순서를 바꾼 뒤 다른 화면에 다녀오면 예전 순서로 보이던 문제.
  저장은 처음부터 정상이었고, 새로고침해야만 맞게 보였습니다
- 달력이 처음 만드는 달의 집계에서 할 일과 루틴 몫이 빠지던 문제.
  체크하거나 할 일을 추가한 직후의 할 일·루틴 개수도 바로 따라오게 고쳤습니다

## ⚠️ Notes

**첫 화면 주소가 바뀌었습니다.**
`/`는 이제 소개 페이지이고 로그인 화면은 `/login`입니다.
로그인한 상태이거나 설치한 앱으로 열면 전처럼 바로 홈으로 갑니다.

**헤더 메뉴가 다섯 개가 되었습니다.**
"기록"이 추가되어 좁은 화면에서는 메뉴 글자와 간격이 조금 작아졌습니다.

**루틴 기록과 기록 화면의 숫자는 달력과 같은 규칙으로 셉니다.**
그날 해야 했던 것이 전체, 그중 체크한 것이 완료이며 오늘 이후는 세지 않습니다.
반복 요일 이력은 고른 기간 안의 날만 세므로, 바꾸기 전 기간이 짧게 걸치면 횟수도 적게 나옵니다.
